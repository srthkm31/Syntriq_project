# Syntriq Internship Projects

This repository contains machine learning projects completed as part of my internship work.

## Projects

### 1. Credit Card Fraud Detection

Built a machine learning model to identify fraudulent credit card transactions. The project includes data preprocessing, feature engineering, model training, evaluation, and deployment using Streamlit.

**Algorithms Used**

* Logistic Regression
* Decision Tree
* Random Forest

**Final Model**

* Random Forest Classifier

### 2. Customer Churn Prediction

Built a machine learning model to predict whether a customer is likely to leave a business based on customer demographics and account information. The project includes data preprocessing, model training, evaluation, and deployment using Streamlit.

**Algorithms Used**

* Logistic Regression
* Decision Tree
* Random Forest

**Final Model**

* Random Forest Classifier

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Streamlit
